# Password and Credential Reset Policy (v2.0)
1. **Check Service Dependencies First:** Before proposing a credential reset, verify whether the target application depends on a service with an active outage (e.g., Identity Provider). If an outage exists, link the request to the open outage instead of resetting credentials.
2. **Verify Context:** Confirm the employee's office and device type before acting.
3. **Human Approval Required:** Every credential reset requires explicit human engineer approval before execution.
